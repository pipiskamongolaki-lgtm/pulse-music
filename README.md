# Pulse — музыкальное приложение

Стильный плеер, который работает на компьютере, телефоне и планшете (это PWA: веб-приложение, которое ставится как обычное).

## Как запустить

1. Дважды кликни **`start-pulse.bat`**. Откроется браузер с Pulse (адрес `http://localhost:5173`).
2. Сервер работает в свёрнутом окне «Pulse server» на панели задач. Пока слушаешь музыку, его не закрывай. Закроешь окно, и Pulse остановится.

Нужен Node.js (на этом компьютере он уже есть).

**Не открывай `app/index.html` двойным кликом.** Браузер не запускает приложение прямо с диска, и получится пустой экран. Если всё же открыл: когда сервер запущен, Pulse сам перейдёт на нужный адрес, а когда нет, покажет подсказку.

## Как установить как приложение

- **Chrome или Edge на компьютере:** справа в адресной строке появится значок установки (монитор со стрелкой). Ещё можно открыть «Настройки» в самом Pulse и нажать «Установить». Появится иконка на рабочем столе и в меню «Пуск».
- После установки Pulse должен открываться и без запущенного сервера: приложение кэширует себя в браузере. Если вдруг не открылся, просто запусти `start-pulse.bat`.

## Откуда музыка (всё легально)

| Источник | Что даёт |
|---|---|
| **Deezer** | Чарты (мир, 14 стран, 16 жанров), поиск почти по всему каталогу, альбомы, артисты. Без ключа играют 30-секундные превью |
| **YouTube** (по твоему ключу) | Полные версии хитов через официальный встроенный плеер YouTube. Видео показывается вместо обложки |
| **Audius** | Полные треки без ограничений (в основном независимые артисты) |
| **Радио** | Тысячи станций со всего мира, музыка в эфире играет целиком |
| **Свои файлы** | mp3, m4a, flac, ogg, wav: копируются в память браузера и играют без интернета |
| **LRCLIB** | Тексты песен, часто с подсветкой строки в такт |

Скачивания с YouTube, ВКонтакте и других сервисов здесь нет и не будет: это нарушает их правила и авторские права.

## Как включить полные треки (5 минут, бесплатно)

1. Открой [Google Cloud Console](https://console.cloud.google.com/projectcreate), войди в Google-аккаунт и создай проект с любым именем.
2. Включи [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com) (кнопка «Включить»).
3. В разделе [Учётные данные](https://console.cloud.google.com/apis/credentials) нажми «Создать учётные данные» → «Ключ API».
4. Скопируй ключ (начинается с `AIza`), открой в Pulse **Настройки → Полные треки из чартов**, вставь и нажми «Сохранить».

Лимит Google: около 100 поисков новых треков в день. Уже найденные треки запоминаются и лимит не тратят. Когда лимит кончится, до завтра снова будут превью.

## Слушать без интернета

- **Треки Audius** можно скачать: «…» у трека → «Скачать для офлайна», или кнопка со стрелкой рядом с «Перемешать», чтобы скачать весь список. Скачанные отмечены зелёной галочкой и лежат в «Библиотека → Офлайн».
- **Свои файлы** («Библиотека → Мои файлы») всегда играют без интернета.
- **Хиты из чартов** (превью Deezer и полные версии через YouTube) сохранять нельзя: это запрещают правила Deezer и YouTube. Без интернета они не играют.
- Когда интернета нет, главная сама показывает только то, что играет офлайн.

## Как поставить на iPhone

1. Открой в **Safari** ссылку **https://pipiskamongolaki-lgtm.github.io/pulse-music/**
2. Нажми «Поделиться» (квадрат со стрелкой) → «На экран „Домой“» → «Добавить».
3. Запускай Pulse с иконки на экране «Домой»: он откроется на весь экран, как обычное приложение.

Скачивать для офлайна нужно уже внутри приложения на iPhone: у каждого устройства своя память.

## Как слушать с телефона

**Сейчас (та же Wi-Fi сеть):** запусти в папке проекта `node server.js --lan` и открой на телефоне адрес, который появится в окне. Windows может спросить разрешение для Node.js в брандмауэре. Так Pulse работает как сайт; установить его на телефон этим способом нельзя (для установки нужен https).

**По постоянной ссылке:** Pulse выложен на GitHub Pages: **https://pipiskamongolaki-lgtm.github.io/pulse-music/**. Ставится на iPhone (Safari → «Поделиться» → «На экран Домой») и Android (Chrome → «Установить приложение»).

Чтобы выложить новую версию после изменений: закоммить их в git и дважды кликни **`publish.bat`**. Через минуту-две сайт обновится.

Важно: любимые, плейлисты и файлы хранятся в браузере каждого устройства отдельно. Перенести их можно через «Настройки → Резервная копия».

## Горячие клавиши (на компьютере)

| Клавиши | Действие |
|---|---|
| Пробел | Играть / пауза |
| Ctrl + → / ← | Следующий / предыдущий трек |
| → / ← | Перемотка на 5 секунд |
| Ctrl + F | Поиск |
| M | Выключить звук |
| L | Нравится |
| Esc | Свернуть плеер |

## Что умеет

- Главная: чарт дня, хиты сейчас, русские хиты и русский рэп (свежие подборки текущего года), чарты стран, альбомы, артисты, Audius, радио, «Ты часто слушаешь».
- Поиск сразу по Deezer, Audius, радио и своим файлам.
- Страницы альбомов, артистов (с похожими исполнителями) и плейлистов.
- Плеер: очередь с перетаскиванием, «Играть следующим», перемешивание, повтор, таймер сна, текст песни, свайпы, управление с экрана блокировки, наушников и медиаклавиш.
- Библиотека: любимые, свои плейлисты, мои файлы, станции, история.
- Тёмная и светлая тема, 6 акцентных цветов, фон подстраивается под цвет обложки.
- После перезапуска открывается на том же треке и той же секунде.

## Файлы проекта

```
start-pulse.bat     запуск двойным кликом
server.js           локальный сервер (без зависимостей)
app/                само приложение: это и выкладывается на хостинг
  index.html, manifest.webmanifest, sw.js
  css/app.css       оформление
  js/main.js        запуск и навигация
  js/player.js      аудио-движок (очередь, источники, экран блокировки)
  js/api/           Deezer, Audius, радио, YouTube, тексты
  js/views/         экраны
tools/make-icons.js рисует иконки
```

Исходный план на Flutter (документ «План музыкального приложения») остаётся в силе как следующий шаг, если захочешь настоящие нативные сборки. Pulse закрывает почти всю его версию 1 и часть версии 2 (радио, таймер сна, тексты песен, резервная копия).
